FUNCIONALIDAD: Agregar Exámenes Dinámicamente desde Modal de Órdenes

DESCRIPCIÓN DEL CAMBIO:
-----------------------
Se implementó la capacidad de agregar nuevos exámenes directamente desde el modal 
de órdenes de laboratorio cuando el usuario busca un examen que no existe en el sistema.

PROBLEMA RESUELTO:
------------------
Anteriormente, si un médico necesitaba incluir un examen que no estaba registrado 
en el sistema, debía salir del modal, ir a la sección de administración de exámenes, 
crear el examen, y luego regresar al modal de órdenes. Esto interrumpía el flujo 
de trabajo y resultaba en una experiencia de usuario deficiente.

SOLUCIÓN IMPLEMENTADA:
----------------------
- Botón "Agregar Examen" que aparece automáticamente cuando no hay resultados de búsqueda
- Validación en tiempo real para evitar nombres duplicados
- Actualización automática de la lista sin recargar la página
- Mensajes informativos para guiar al usuario

FLUJO DE USO:
-------------
1. Usuario abre modal de órdenes de laboratorio
2. Escribe en el buscador de exámenes (mínimo 2 caracteres)
3. Si no encuentra resultados, aparece botón "Agregar Examen"
4. Usuario hace clic en el botón
5. Sistema solicita confirmación
6. Se crea el examen en la base de datos con:
   - Nombre ingresado por el usuario
   - Código generado automáticamente
   - Tipo de examen por defecto
   - Estado activo
7. Lista de exámenes se actualiza automáticamente
8. Nuevo examen aparece en la lista y puede ser seleccionado
9. Buscador se limpia y botón se oculta

CONFIGURACIÓN DE BASE DE DATOS:
-------------------------------
El nuevo examen se crea con los siguientes valores:
- nombre_examen: Texto ingresado por usuario
- codigo_examen: Código auto-generado (primeras 3 letras + número aleatorio)
- detalle_examen: "Examen agregado desde orden de laboratorio"
- tipo_examen_id: Primer tipo de examen activo en el sistema
- estado_examen: 1 (activo)
- es_principal: 1 (principal)

RUTAS AGREGADAS:
----------------
POST /examen/agregar
- Controlador: examenController@agregar
- Función: Crear nuevos exámenes con validación
- Parámetros: nombre_examen
- Respuesta: JSON con resultado de la operación

GET /examen/lista
- Controlador: examenController@lista
- Función: Retornar vista actualizada de exámenes
- Parámetros: consulta_id (opcional)
- Respuesta: HTML del componente cuadro-examenes

VALIDACIONES IMPLEMENTADAS:
---------------------------
- Usuario debe estar autenticado
- Nombre del examen es requerido
- Mínimo 2 caracteres para el nombre
- Máximo 255 caracteres
- Nombre debe ser único en la base de datos
- Debe existir al menos un tipo de examen activo
